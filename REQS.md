# User Requirements

## Platform coverage

- Prioritize Ubuntu 26.04, Windows 11, and macOS, in that order. Each tool guide may cover only relevant platforms; covering all three is optional.
- Clearly distinguish native Ubuntu from WSL-specific instructions.

## Quick start

- Make each tool’s purpose and platform-specific installation easy to find.
- Provide a concise quick start for each covered platform, including installation, configuration, verification, and first use. Keep commands together where practical; separate manual file edits from terminal commands.
- For manual edits, show the file to open, the exact content to add or change, and verification in a new terminal.
- Keep commands ready to copy, with short comments and clearly marked substitutions.
- State prerequisites before the commands.
- Prefer official installation methods and direct configuration, without unnecessary helper scripts.

## Everyday use

- Provide practical examples for common tasks.
- Explain how to update, troubleshoot, and uninstall tools.
- Include configuration backup and recovery steps where needed.

## Trust and safety

- Clearly identify tested instructions and unverified guidance.
- Explain commands that require elevation, execute downloaded code, or make destructive or system-wide changes.
- Link to official documentation for further details.
